1️⃣ PRICE VARIANCE PROXY (R5)
   When standard_cost is NULL: use proxy formula
   price_variance = UnitPrice - (UnitPrice * 0.85)  [15% margin assumption]

2️⃣ TOTAL SPEND AGGREGATION (R5)
   Added: F.round(F.sum("subtotal"), 2) for total_spend
   Properly aggregated at vendor-ship_method level

3️⃣ DISTINCT PO COUNTING (R5) ⭐ CRITICAL
   Changed: count() → countDistinct(purchaseorderid)
   Why: One PO can have multiple line items, we count POs not items
   Example: PO with 3 line items = 1 order (not 3)

4️⃣ VENDOR SCORE EDGE CASES (R6)
   Formula: (on_time_rate * 0.6) + ((100 - |price_variance|) * 0.4)
   Edge case: Score clamped to 0 minimum using F.greatest()
   Prevents negative scores when price_variance > 100

5️⃣ OVERALL RANKING WINDOW (R8)
   Fixed: Window function must be defined AFTER groupBy/agg
   Was: win_overall = Window.orderBy(...) BEFORE aggregation ❌
   Now: Correct Spark pattern with window after aggregation ✅

6️⃣ OUTPUT COLUMNS (R7)
   Explicit column selection matching specification:
   [vendor_id, vendor_name, credit_rating, ship_method,
    total_orders, on_time_orders, on_time_rate, total_spend,
    avg_price_variance, vendor_score]
